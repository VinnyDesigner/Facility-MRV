# Assets Directory (`src/assets/`)

This directory is for static and modular media assets used throughout the **Facility MRV** application.

## Recommended Structure:
- `images/`: Facility photos, background textures, operator avatars.
- `icons/`: Custom environmental icons, UAE emblems, EAD badges.
- `docs/`: Sample MRV report templates, verification statement templates.

## Usage in React:
```tsx
import logo from './assets/logo.svg';
// or reference public assets directly:
// <img src="/assets/logo.svg" alt="Logo" />
```
